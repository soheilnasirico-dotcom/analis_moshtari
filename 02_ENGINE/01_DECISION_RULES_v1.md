# OptiVanc — Website Strategy Decision Rules v1

## Input
Structured Customer Discovery state + evidence + constraints.

## Output chain
Website Role → Primary Conversion → Website Type → IA → Page Goals → UX Strategy → Content Strategy → Feature Decisions → Requirements → Technical Direction

## Rules
- Website Role is derived from business goal + user journey.
- Choose one Primary Conversion; secondary actions may exist.
- Website Type must be justified by business model, buying journey and conversion model.
- Candidate pages require a user/business decision they support.
- Page priority = business impact + user need + conversion contribution.
- Trust requirements derive from actual objections and proof.
- Content requirements derive from decision-making information gaps.
- Feature decisions require a problem/user/outcome/alternative analysis.
- Technical decisions happen after functional, UX and content requirements.
- If evidence is insufficient, output OPEN QUESTION / DEPENDENCY rather than inventing a decision.
